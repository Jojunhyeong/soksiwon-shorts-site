개인정보처리방침

시행일: 2026년 11월 25일

1. 누가 쓰는 도구인가요

「속이시원 쇼츠 도우미」는 유튜브 채널 「속이시원」 운영자가 본인 채널 운영을 위해 만든 개인용 도구입니다. 다른 사람에게 서비스로 제공되지 않으며, 운영자 본인의 Google 계정으로만 로그인합니다.

2. 어떤 정보를 쓰나요

  • 운영자 본인 채널의 영상 목록, 예약 공개 시각, 제목과 자막
  • 쇼츠 영상 업로드, 쇼츠에 롱폼 안내 댓글 달기, 썸네일 변경에 필요한 YouTube 권한

다른 사람의 개인정보나 시청자 정보는 모으지 않습니다.

3. 어디에 저장하나요

로그인 정보와 작업 파일은 운영자 본인의 컴퓨터에만 저장됩니다. 외부 서버에 따로 저장하거나 다른 사람과 공유하지 않습니다.

4. 누구에게 넘기나요

YouTube Data API를 통해 운영자 본인 채널에 영상을 올리고 고치는 것 외에는, 정보를 제3자에게 팔거나 넘기지 않습니다. 이 도구의 YouTube 데이터 사용은 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 권한을 거두려면

Google 계정의 타사 액세스 설정에서 언제든지 이 도구의 접근 권한을 해제할 수 있습니다.
